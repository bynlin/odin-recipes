# odin-recipes

Odin Recipes

Odin Recipes started as a food recipe website built while following The Odin Project. Since then, it has grown into something more than a collection of recipes.

The project now has two main sections:

Food recipes:
A collection of found recipes and some terriblly written recipes of dishes I love that my mum has taught me. Erm, they're terrible only because there are no proper measurements of ingredients nor cooking time, everything is mostly 'aga-aga', which translates into 'go by your instincts'.

Code recipes:
A collection of quick notes from learning to code, along with coding exercises and tutorials I like and find useful, such as an adaptive photo layout built with Flexbox.

Odin Recipes will continue to be a space where I can collect recipes, document what I learn, experiment with code, and sandbox tutorials as I explore web development.
