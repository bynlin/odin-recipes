Notes

min-height: 100svh;

  1. What happens when we set min-height: 100svh; on body
  2. min-height sets the min height of an element where no matter what else happens, this body cannot shrink smaller than the min-height set. We're telling the browser: "Even if body is empty or that height is set to 50px—this body must be at least 100svh tall.""
  3. Common use cases:
    1. Sticky footers:
      Even on a nearly empty page, your footer gets pushed down to the absolute bottom of the screen
    2. Full-screen Hero Sections:
      Ideal for landing page landing spots or splash pages that fills the screen completely like a billboard image, and on mobile where the phone screen is too narrow and the text or content gets too long, let the section stretch downward to fit all the words perfectly.
    3. Centered Authentication Pages:
      Commonly used for Login, sign-up and password-reset screens that typically feature a single, isolated form card centered horizontally and vertically on the screen.
      Set min-height:100svh; paired with display:grid; place-items:center; on the body ensures the card is precisely within the true visible window. If the user rotates their phone horizontally and the form overflows, the min-height safely lets the page grow and become scrollable.

Quick Jot

  1. Use rem for spacing and font-sizes
  2. Use em for component intervals
  3. Use px for borders and shadows
  4. Spacing between items: Use gap with flexbox or grid
  5. Layout: Use grid for two directions or use flexbox for two
  6. Selectors: Classes, plus + or :not () for when you need to skip the first or last item, for example: .prose li + li {margin-top:0.25em} or .prose li:not(:first-chiled) {margin-top: 0.25em}
